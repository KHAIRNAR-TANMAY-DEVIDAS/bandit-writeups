# OverTheWire: Bandit Walkthroughs

My documented journey through the Bandit wargame — prepping for a SOC/security analyst role.

## Why I'm doing this
Documenting every step to practice clear technical writing, since documentation
(incident notes, runbooks) is a core SOC skill.

## Structure
Each `levelXX-XX.md` covers one level: goal, commands used, reasoning, and lesson learned.
Passwords are hidden behind spoiler tags out of respect for others still solving.
